# Windows Run Commands (Win + R)

Press `Win + R`, then type the command below and press Enter.

## Core Tools
- `cmd` — Command Prompt
- `powershell` — PowerShell
- `wt` — Windows Terminal
- `control` — Control Panel
- `msinfo32` — System Information
- `dxdiag` — DirectX Diagnostic
- `services.msc` — Services console
- `devmgmt.msc` — Device Manager
- `compmgmt.msc` — Computer Management
- `taskmgr` — Task Manager
- `eventvwr` — Event Viewer
- `regedit` — Registry Editor (be careful)

## Network/Admin
- `ncpa.cpl` — Network Connections
- `wf.msc` — Windows Defender Firewall with Advanced Security
- `lusrmgr.msc` — Local Users and Groups (Pro/Enterprise)
- `gpedit.msc` — Local Group Policy (Pro/Enterprise)
- `secpol.msc` — Local Security Policy (Pro/Enterprise)

## Apps & Settings
- `appwiz.cpl` — Programs and Features
- `inetcpl.cpl` — Internet Options
- `powercfg.cpl` — Power Options
- `main.cpl` — Mouse settings
- `mmsys.cpl` — Sound settings
- `osk` — On-screen keyboard
- `calc` — Calculator
