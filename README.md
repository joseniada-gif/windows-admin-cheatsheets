# Windows Admin Cheatsheets

A compact, public-friendly reference for everyday Windows administrators and power users.

## What's inside
- **windows-cmd-cheatsheet.md** — Common Command Prompt (cmd.exe) commands with examples.
- **windows-run-commands.md** — Handy `Win + R` run dialog commands.
- **admin-tasks.md** — Common troubleshooting / admin flows (copy‑pasteable).
- **scripts/** — Small, safe demo scripts (.bat) for learning/testing.

> All content is safe to run on a normal workstation. No destructive commands are included.
